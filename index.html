CosmeDB TAB05 이용 가이드

1. 사용방법 — 8단계로 끝내기

  1. (선택) API 설정 — 우측 상단 [API 설정]에서 Gemini · 공공데이터 · 네이버 · ECOS 키를 등록하면 실시간 수집이 가능합니다. 키가 없어도 GitHub Actions가 6시간마다 자동 수집한 데이터로 분석할 수 있습니다.
  2. [전체 수집 실행] 클릭 — 기후·사회·경제·문화 4대 신호와 수출·구매·검색·뉴스 모멘텀을 한 번에 수집합니다. 화면 상단 상태바의 점(●) 색으로 진행상황을 확인하세요. (회색=대기 · 노란색=수집중 · 초록=완료 · 빨강=오류)
  3. ZONE 0 — 4대 신호 카드에서 기후·사회·경제·문화 4개 영역의 점수(5점 만점)와 해설을 확인합니다. 카드를 클릭하면 원시 지표·기사·RSS 링크 등 "분석 근거 자료" 모달이 열립니다 (예: 문화·팝트렌드 클릭 → RSS·뉴스 근거 기사 목록).
  4. ZONE 1 — 예측 TOP5: Gemini가 위 데이터를 종합 분석해 도출한 "앞으로 뜰 화장품 유형 TOP5"가 표시됩니다. 상단 탭으로 6개월 / 1년 예측을 전환할 수 있습니다.
  5. TOP5 항목을 클릭하면 ZONE 2 — 제조사 매칭에 TRACK A(기등록 업체) · TRACK B(신규처 후보)가 자동으로 표시됩니다.
  6. ZONE 3 — 법령·규제에서 최신 화장품 관련 법령·고시 변경사항을 시행일 기준 긴급도별로 확인합니다.
  7. [BM 보고서] → [보고서 생성]을 클릭하면 지금까지의 분석 결과가 텍스트로 정리됩니다. [복사]로 보고서·회의자료에 바로 활용하세요.

2. 분석방법 — 예측은 어떻게 만들어지나요?

4대 신호 (ZONE 0) — 시장 전체에 공통 적용되는 매크로 지표, 각 5점 만점
  • 기후·환경 — 기상청 기온·UV지수 + 에어코리아 대기질. 계절·환경 변화가 쿨링·자외선차단·보습 수요에 미치는 영향을 봅니다.
  • 사회·인구 — KOSIS 1인가구·고령화 통계. 인구구조 변화가 만드는 새 수요(맨즈뷰티, 안티에이징 등)를 봅니다.
  • 경제·리테일 — ECOS 소비자물가(CPI)·원자재가 + 관세청 화장품 HS코드별 수출실적. 원가 부담과 실제 판매 실적을 봅니다.
  • 문화·팝트렌드 — 네이버 검색·뉴스 + 뷰티 RSS. 신제품·트렌드 키워드의 화제성을 봅니다.
모멘텀 4종 (ZONE 0 카드 클릭 → 분석 근거 자료) — 카테고리별 "최근 vs 직전 기간" 증감률(%)
  • REAL수출 모멘텀 — 관세청 HS코드별 실제 수출액. 가장 신뢰도 높은 "실판매" 신호로 Gemini 예측에서 최우선 가중됩니다. 경제·리테일 카드 클릭 시 확인.
  • 구매 모멘텀 — 네이버쇼핑인사이트 화장품 카테고리 클릭량 추이. "구매 의도"를 나타냅니다. 문화·팝트렌드 카드 클릭 시 확인.
  • 검색 모멘텀 — 네이버데이터랩 검색량 추이. "관심도"를 나타냅니다. 문화·팝트렌드 카드 클릭 시 확인.
  • 뉴스·RSS 모멘텀 — 뷰티 트렌드 키워드의 뉴스·RSS 언급빈도와 실제 기사 제목·링크. 문화·팝트렌드 카드 클릭 시 근거 기사 목록(RSS 분석 근거 자료 포함)을 확인.
Gemini 예측 (ZONE 1)

위 4대 신호와 모멘텀 데이터를 하나의 프롬프트로 전달하면, Gemini가 대형 3사(한국콜마·코스맥스·코스메카코리아)는 언급하지 않고 다른 OEM/ODM이 진입 가능한 화장품 유형 TOP5를 신뢰도(%) · 권장 패키징 · 출시 적기(계절)와 함께 도출합니다. 각 항목의 "근거 신호" 칩은 4대 신호 중 어떤 요인이 가장 크게 작용했는지를 보여줍니다.

제조사 매칭 (ZONE 2)
  • TRACK A — 기등록 업체: 내부 DB에서 예측 카테고리·인증과 일치하는 업체를 즉시 조회합니다. (바로 컨택 가능)
  • TRACK B — 신규처 후보: KIPRIS 특허·네이버뉴스·네이버블로그·네이버쇼핑·식약처 데이터를 Gemini가 분석해 "생산했던 / 생산하는 / 생산가능" 후보를 탐색합니다. 추측(생산가능) 후보는 ▲네이버쇼핑 판매 제품의 제조사(maker) 필드 역추적 ▲블로그 후기·체험기 내용 추적 ▲업체 공식 홈페이지 웹문서 검색으로 근거를 추가 보강합니다. 근거 카드의 [근거 자료 열기] 버튼으로 실제 출처 링크를 바로 확인할 수 있습니다.
법령·규제 모니터링 (ZONE 3)

화장품 관련 최신 법령·고시·가이드라인을 자동 수집해 시행일 기준 긴급도(D-day)에 따라 색상으로 구분 표시합니다. 각 항목 하단의 링크를 클릭하면 해당 규제를 관할하는 기관(식약처·EU EUR-Lex·美 FDA·KMF 등)의 공식 홈페이지로 이동해 근거 자료를 확인할 수 있습니다.
